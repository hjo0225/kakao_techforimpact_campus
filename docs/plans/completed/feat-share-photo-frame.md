# 직관 공유카드 — 셀카 + 마스코트 포토 합성으로 재설계

## 요청
- 직관 공유 = 사용자가 찍은 사진 위에 프레임을 씌우는 형태(네컷사진처럼).
- 기존 프레임 내용(기본 템플릿 포함) 전부 제거.
- 프레임 하단에 승리/패배 두 버튼.
- "이번 시즌 잠실 직관 N번째"(백엔드 직관 달력 연동) 문구 + 제공된 승리/패배 마스코트 이미지와 셀카를 함께 합성.
- 모바일에서 다운로드가 제대로 안 됨 → 수정.

## 결정 (사용자 확인)
- N = **이번 시즌(2026) 잠실 직관만** 카운트.
- 출력 = **인스타 스토리 9:16 (1080×1920)** 단일.
- 마스코트 자산: `승리.png`/`패배.png`(픽셀아트 토끼, 투명 PNG, 820×1024) → `frontend/src/assets/share-win.png`, `share-lose.png`.

## 변경 (`frontend/src/app/components/screens/RecordScreen.tsx`)
- `createInstagramReadyImage` 재작성: 셀카 cover 배경(없으면 그라데이션) + 상단 "이번 시즌 잠실 직관 / N번째" + 하단 우측 마스코트(높이 50%). 기존 템플릿 내용(용기낼깡 배지·날짜·경기명·스코어·승리!·환경행동 박스·해시태그) 전부 제거.
- 상태: `shareFormat`(story/feed) 제거 → `gameResult: 'win' | 'lose'`. `shareFile` 상태 추가.
- `visitN` 계산: `visits`(attendance 직관 달력)에서 `2026 & venue 잠실` 필터 + 오늘 선택분 포함(`Math.max(...,1)`). 백엔드 변경 불필요.
- **공유 이미지 미리 생성**(useEffect): 클릭 시 user-gesture 안에서 동기로 `navigator.share()` 호출 가능 → 모바일 공유/저장 안정화.
- `handleShareCard`: Web Share(파일) 우선 → 미지원 시 이미지를 새 탭으로 열어 길게눌러 저장(팝업 차단 시 다운로드 fallback).
- 공유 탭 UI: 포맷 토글·기존 미리보기·기본 문구 템플릿 제거 → 9:16 라이브 미리보기(셀카+마스코트+N) + 승리/패배 토글 + 사진 선택/촬영 + 공유 버튼.

## 검증
- `npm run build` 통과.
- PIL 합성 미리보기로 배치/비율 확인.
- 수동(모바일 권장): 사진 선택 → 승/패 토글 → 공유 시트/저장 확인.

## 비고
- 마스코트 크기/위치(현재 높이 50%, 하단 우측 36px 여백)는 쉽게 조정 가능.
- "승패"는 사용자가 직접 선택(실제 경기 결과 데이터 미연동).
