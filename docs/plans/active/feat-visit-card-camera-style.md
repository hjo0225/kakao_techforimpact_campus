# Plan: 직관카드 화면을 카메라앱 스타일로 재구성 (프레임 캐러셀)

## 결정
프레임이 늘어날 예정 → A(프레임 선택 후 촬영 분기) vs B(카메라앱 스타일) 중 **B 채택**.
이유: 사진을 한 번 찍고 프레임을 좌우로 넘기며 **내 사진에 바로 미리보기·비교** 가능(프레임 증가에 강함),
단계·이탈 없음, 현재 "사후 프레임 적용" 구조에 정확히 부합.

## 레이아웃 (위→아래)
- 헤더: 용도 토글(좌, flex) + **저장 버튼(우상단)**
- 가운데: 1:1 카드 프리뷰(가변, 중앙). 사진 전이면 촬영 안내 오버레이
- 네비 위: **프레임 가로 스크롤 캐러셀**(스냅) — 썸네일=마스코트+라벨, 선택 시 즉시 카드 재렌더
- 토스트: 캐러셀 위에 떠오르는 플로팅

## 동작
- 중앙 카메라 버튼 = 촬영(기존 registerCameraAction 유지)
- 프레임 선택 → `frameKey` 변경 → `createCardImage` 재렌더(가벼움)
- 저장 = `ensureSaved`(서버 저장→캘린더) + 다운로드 (기존 유지)

## 기타
- 공유 제거에 맞춰 토글 설명 문구 "만들고 공유해요" → "만들어 저장해요"
- 미사용 `cardStyle` 제거

## 완료 기준
- 헤더 우상단 저장, 가운데 1:1 프리뷰, 하단 프레임 캐러셀로 즉시 전환 (puppeteer 시각 확인)
- typecheck/build 통과
