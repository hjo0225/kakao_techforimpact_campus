# Plan: 직관카드 라이브 카메라 (Phase 1)

## 목표
`<input capture>`(OS 카메라 호출) → **앱 내 라이브 카메라(getUserMedia)**로 전환. 웹/안드로이드 동일 동작.

## 화면 (직관카드 모드 = VisitCard)
- **상단바**: 모드 토글(인증/직관카드, 중앙) + 전/후면 전환(우)
- **뷰파인더**: 라이브 카메라(1:1, cover). 권한 거부/카메라 없음 → 에러 + 파일선택 폴백
- **하단 제어부 (촬영 전)**:
  - 상단 탭: 촬영 | 비디오 (비디오는 Phase 3 — 비활성 "준비 중")
  - 좌: 프레임 → 하단을 프레임 캐러셀로 전환
  - 중앙: 하늘색 큰 원형 촬영 버튼
  - 우: 이모지 (Phase 2 — 비활성 "준비 중")
- **촬영 후(result)**: 사진+프레임 합성 표시 / 하단: ◀뒤로(재촬영) + ⬇다운로드(=저장)

## 동작/재사용
- 촬영 = `<video>` 프레임 → canvas(1080² cover) → File → 기존 `createCardImage` 합성 파이프라인 재사용
- 저장 = 기존 `ensureSaved`(서버 저장→캘린더) + 다운로드
- 전면 카메라는 프리뷰/캡처 미러링
- 스트림은 카메라 뷰에서만 켜고 result/언마운트 시 정지(트랙 stop)

## 비고
- 촬영 버튼 "하늘색"은 DESIGN.md 토큰 밖 — 카메라 컨트롤 한정 사용(추후 토큰화 가능)
- 인증(verify) 모드 카메라 라이브 전환은 후속(현재 플로우 유지)

## 완료 기준
- 라이브 뷰파인더 + 전/후면 전환 + 프레임 선택 + 촬영→합성→저장/다운로드 동작
- 권한 거부/카메라 없음 시 파일선택 폴백
- typecheck/build 통과, 시각 검증(fake media)
